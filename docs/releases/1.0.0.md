# StalkShift 1.0.0

## English

Use MOZA Multi-function Stalks to control indicators, lights, wipers, horn, hazard lights, gears, parking brake and cruise in ETS2. Optional cruise adjustment follows the road limit supplied by the game.

1. Download **StalkShift-1.0.0-windows-x64.zip** below and extract the whole folder.
2. Close ETS2 and open **Install.cmd**. Choose your language and game profile.
3. Connect the stalks by USB, select **Multi function key switch direct** in Pit House, open **Start.cmd**, then launch ETS2.

[Installation and help](https://github.com/Moltenship/stalkshift/blob/v1.0.0/README.md) · [All controls](https://github.com/Moltenship/stalkshift/blob/v1.0.0/docs/controls-en.md)

The right stalk selects D / N / R / P from bottom to top. P selects neutral and applies the parking brake; leaving P releases it. Pulling towards you holds the horn, pressing below D toggles the brake once, and doing both activates both functions.

Installation supports English and Russian, finds Steam game folders and can remove duplicate stalk button assignments while preserving other controls. Uninstall.cmd removes the plugin and restores unchanged profile assignments from backup. No programming tools are needed.

Windows x64 only. Game testing used ETS2 1.60.1.7 with standard New Actros and Scania trucks. ATS, H-pattern shifters and truck mods are not verified. Wiper animations depend on the truck. Speed-limit cruise adjustment requires kilometres and a 5 km/h cruise step. Release binaries are not code-signed. SHA256SUMS.txt contains the ZIP checksum.

## Русский

Управляйте поворотниками, светом, дворниками, клаксоном, аварийкой, передачами, ручником и круизом в ETS2 с MOZA Multi-function Stalks. Дополнительно можно включить подстройку круиза под ограничение дороги из игры.

1. Скачайте **StalkShift-1.0.0-windows-x64.zip** ниже и распакуйте всю папку.
2. Закройте ETS2 и откройте **Install.cmd**. Выберите язык и игровой профиль.
3. Подключите переключатели по USB, выберите **Multi function key switch direct** в Pit House, откройте **Start.cmd**, затем запустите ETS2.

[Установка и помощь](https://github.com/Moltenship/stalkshift/blob/v1.0.0/README.ru.md) · [Все назначения](https://github.com/Moltenship/stalkshift/blob/v1.0.0/docs/controls-ru.md)

Правый рычаг выбирает D / N / R / P снизу вверх. P включает нейтраль и ручник; выход из P снимает ручник. Движение к себе удерживает клаксон, нажатие ниже D переключает ручник один раз. При сочетании движений работают обе функции.

Установка доступна на русском и английском, находит папки игры в Steam и позволяет убрать дублирующие назначения кнопок переключателей, сохранив остальное управление. Uninstall.cmd удаляет плагин и восстанавливает назначения профиля из копии, если их не меняли после установки. Инструменты для программирования не нужны.

Только Windows x64. Игровые проверки проводились в ETS2 1.60.1.7 на стандартных New Actros и Scania. ATS, H-образные коробки и грузовики из модов не проверены. Анимации дворников зависят от грузовика. Подстройке круиза нужны километры и шаг круиза 5 км/ч. Файлы релиза не имеют цифровой подписи. Контрольная сумма ZIP находится в SHA256SUMS.txt.
