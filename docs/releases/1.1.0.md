# StalkShift 1.1.0

## English

StalkShift now supports **Euro Truck Simulator 2 and American Truck Simulator** in one Windows download. Both games use the same stalk assignments.

- Choose the game in Install.cmd, Start.cmd and Uninstall.cmd when both are available.
- Each game keeps its own installation settings and profile backups. Removing one does not change the other.
- Choose km/h or mph to match your game. Automatic cruise adjustment supports both, with a five-unit cruise step configured in the game.
- Updating from 1.0 preserves ETS2 profile backups and their restoration history.

Download **StalkShift-1.1.0-windows-x64.zip**, extract the whole folder, close both games and StalkShift, then open **Install.cmd**. To use both games, install once for each. Open **Start.cmd** before playing. Keep Pit House in **Multi function key switch direct** mode and run one simulator at a time.

[English guide](https://github.com/Moltenship/stalkshift/blob/v1.1.0/README.md) · [All controls](https://github.com/Moltenship/stalkshift/blob/v1.1.0/docs/controls-en.md)

Validation includes automated ETS2/ATS DLL initialization and callbacks, independent installation/removal, 1.0 migration, cruise calculations in both units and regression tests. ATS has not been tested in the game. Existing game confirmations are from ETS2 1.60.1.7. Windows x64; release files are not code-signed. SHA256SUMS.txt contains the ZIP checksum.

## Русский

StalkShift теперь поддерживает **Euro Truck Simulator 2 и American Truck Simulator** в одном архиве для Windows. Назначения переключателей одинаковы для обеих игр.

- Выбирайте игру в Install.cmd, Start.cmd и Uninstall.cmd, если установлены обе.
- Настройки установки и резервные копии профилей хранятся отдельно. Удаление для одной игры не меняет вторую.
- Выбирайте км/ч или мили/ч в соответствии с игрой. Подстройка круиза поддерживает оба варианта, если в игре задан шаг изменения скорости круиза в пять единиц.
- Обновление с 1.0 сохраняет резервные копии профилей ETS2 и возможность их восстановления.

Скачайте **StalkShift-1.1.0-windows-x64.zip**, распакуйте всю папку, закройте обе игры и StalkShift, затем откройте **Install.cmd**. Для двух игр выполните установку по одному разу для каждой. Перед игрой открывайте **Start.cmd**. В Pit House используйте режим **Multi function key switch direct**. Запускайте один симулятор за раз.

[Русская инструкция](https://github.com/Moltenship/stalkshift/blob/v1.1.0/README.ru.md) · [Все назначения](https://github.com/Moltenship/stalkshift/blob/v1.1.0/docs/controls-ru.md)

Автоматически проверены загрузка DLL и обработка вызовов для ETS2/ATS, независимая установка и удаление, обновление с 1.0, расчёты круиза в обеих единицах и прежние функции. В самой ATS проверка не проводилась. Существующие игровые подтверждения относятся к ETS2 1.60.1.7. Только Windows x64; файлы релиза без цифровой подписи. Контрольная сумма ZIP находится в SHA256SUMS.txt.
