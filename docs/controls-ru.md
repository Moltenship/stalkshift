# StalkShift — общая проверка управления

Сборка с протоколом v3 реализует все записанные органы MOZA Multi-function Stalks в режиме **Multi function key switch direct**. Новые функции ещё проходят игровую приёмку; успешные автоматические тесты не заменяют эту проверку.

## Подготовка

- Установить DLL и EXE из одной сборки, запустить мост, загрузить кабину. Для D/N/R/P использовать автоматическую или последовательную коробку; режим H-shifter отдельно не подтверждён.
- Убрать прямые назначения этих же кнопок stalks в ETS2 и клавиатурную адаптацию Pit House. Остальные назначения клавиатуры, руля и педалей сохраняются.
- Для автоматической подстройки: километры, шаг круиза **5 км/ч**, отображаемое ограничение скорости в навигаторе.
- После загрузки, паузы или переподключения отпустить подпружиненные органы и заново сдвинуть нужные переключатели. Для REAR сначала верхнее фиксированное → OFF: мост должен узнать положение OFF, прежде чем отличать нижнее подпружиненное движение от верхнего.

## Назначения

| Орган | Действие |
|---|---|
| Левый рычаг вверх/вниз и центр | Поворотники и выключение |
| Кольцо света OFF / маленькие фары / большая фара | Выключено / габариты / ближний |
| Левый рычаг к себе | Мигание фарами до отпускания |
| Левый рычаг от себя | Дальний включить/выключить один раз |
| Маленькое колёсико дворников OFF / INT / LO / HI | Выключено / прерывистый / медленный / быстрый |
| MIST | Один взмах при входе в положение |
| Правый рычаг, фиксированные положения снизу вверх | D / N / R / P |
| P | Нейтраль и включение стояночного тормоза, если он был выключен |
| Правый рычаг к себе | Клаксон до отпускания; доступен в трёх нижних положениях |
| Правый рычаг ниже нижнего фиксатора | Переключить стояночный тормоз один раз |
| REAR из OFF вниз с возвратом | Переключить аварийку один раз |
| REAR вверх с возвратом из верхнего фиксированного | Без игрового действия |
| Крутилка ON/OFF на рычажке круиза | Включить/выключить круиз |
| Рычажок круиза к себе | Возобновить выключенный круиз / отменить включённый |
| Рычажок круиза вверх / вниз | Увеличивать / уменьшать заданную скорость при удержании |
| Маленький подпружиненный переключатель с кружком и фарой слева | Включить/выключить автоматическую подстройку круиза под ограничение |

При выходе из P стояночный тормоз автоматически не отпускается: выключить его можно нижним подпружиненным движением или обычным игровым управлением.

Автоподстройка изначально выключена и сама круиз не включает. На включённом круизе она выбирает ближайшую достижимую скорость с шагом 5 км/ч, не выше ограничения. Ручное действие круизом выключает автоподстройку; левым переключателем можно включить её снова. При неизвестном ограничении она ждёт. Если игра не принимает шаг, попытки прекращаются до изменения ограничения или нового включения режима. После паузы/переподключения режим снова выключен. Его состояние видно в консоли как `auto=true/false`.

## Один общий проход

1. **На месте, с зажиганием:** проверить поворотники, кольцо света, мигание и дальний; затем OFF → INT → LO → HI → OFF по 10 секунд и MIST на 10 секунд. Отметить различия скоростей и число взмахов.
2. **На месте, удерживая рабочий тормоз:** пройти D → N → R → P и обратно. Проверить, что P включает стояночный тормоз, а повторный вход в P не выключает уже включённый. Дважды проверить нижнее подпружиненное движение: каждое переключает тормоз один раз, удержание не повторяет действие.
3. **На месте:** удержать клаксон и отпустить; проверить аварийку двумя нижними движениями REAR из OFF. Удержание не должно повторять переключение. Верхнее подпружиненное движение не должно менять аварийку.
4. **В движении, где игра разрешает круиз:** проверить ON/OFF, отмену/возобновление и удержания вверх/вниз. Затем включить автоподстройку левым переключателем и сравнить цель круиза с ограничением навигатора. Ручное изменение должно вернуть управление тебе.
5. **Пауза и перезапуск игры:** управление возвращается после свежего движения; клаксон не зависает, передачи и круиз не включаются сами. Повторить после отключения USB. Мост должен восстановить связь без ручного перезапуска.

Сообщить модель Scania и результат по пунктам: что совпало, что не сработало и какое физическое движение вызвало проблему. Тестировать всё повторно после каждого замечания не нужно.
